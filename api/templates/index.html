Routes in blue can be opened directly. The rest need an ID or a JSON body (Content-Type: application/json). IDs use the format <prefix>-<alphanumeric>, e.g. cmp-001, pc-001, sale-001.

Errors are returned as {"error": "...", "status": code}: 400 invalid data, 404 not found, 500 server error.
